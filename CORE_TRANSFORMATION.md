## 🎬 Animation Guidelines

### Entrance Animations
- Use `animate-fade-in` for general content
- Use `animate-slide-up` for modals
- Use `message-enter` for chat messages
- Delay with `style={{ animationDelay: '0.2s' }}`

### Hover Animations
- Scale: 1.05 max for cards
- Transform: translateY(-4px) for lift
- Glow: increase shadow spread
- Duration: 300ms standard

### Loading States
- Use `animate-pulse` for loading
- Use typing dots with glow
- Apply shimmer to placeholders
- Spinner with gradient border

## 🔧 Troubleshooting Guide

### Visual Issues
**Glow not visible?**
- Ensure proper z-index stacking
- Check parent positioning
- Verify shadow classes applied

**Glass effect missing?**
- Confirm backdrop-filter support
- Check background transparency
- Verify blur value

**Animation stuttering?**
- Use transform instead of position
- Check will-change usage
- Reduce simultaneous animations

### Color Issues
**Contrast too low?**
- Increase opacity values
- Use lighter text shades
- Add text shadows if needed

**Gradients not smooth?**
- Add more color stops
- Adjust color distances
- Use similar hue ranges
